# Changesets

Welcome! This directory contains configuration and pending change summaries for changesets.

## Adding a changeset

Whenever you make changes to `satteri-reladraw`, create a new changeset by running:

```bash
bun run changeset
```

Follow the prompts to select the change bump type (patch, minor, major) and provide a summary of your changes.

Commit the generated markdown file along with your PR.
